# 요구사항 정의서 (초안)

종합 여행 플래너 Agent — 국가유산 + 관광지 + 음식점 + 카페를 한 일정에 묶고, 이동 수단별로 "어디서 무엇을 타고 몇 시에 도착하는지"까지 안내한다. 명세서의 필수 요구사항은 수정 없이 지키고, 표현만 여행 도메인에 맞게 바꿨다.

상태: ✅ 뼈대 구현·테스트 / 🟡 일부 구현 / ⬜ 미구현

## 기능적 요구사항

| 번호 | 분류 | 요구사항명 | 상세 (여행 도메인) | 우선순위 | 상태 |

| F3002 | Tool | 후보 조회 Tool | 국가유산청(국보·보물·사적) + TourAPI(관광지·축제·음식점) + 카카오 로컬(카페) 로 후보 확보, 한 API로 부족한 후보는 다른 API로 보충 | 필수 | 🟡 국가유산청·카카오 구현, TourAPI 경로 1일차 확인 |

| F3004 | Tool | 보조 정보 Tool | 이동 수단별 구간(TAGO 열차·고속·시외, 카카오모빌리티, ODsay), 날씨, 공휴일, 혼잡 | 필수 | 🟡 자가용·공휴일 구현 |

| F3006 | Agent | 작업 계획 수립 | 필요한 Tool 만 순서대로, Tool 불필요 요청은 계획 생략 | 필수 | 🟡 |
| F3007 | Agent | Tool 호출 및 결과 통합 | 앞선 결과를 다음 입력으로, 실패해도 사유 기록 후 진행 | 필수 | ✅ |
| F3008 | Agent | 제약 적합성 판단 | 시간 예산(체류시간 없으면 곳당 최대 N분 역산), 운영시간·휴무, 식사·카페 슬롯, 막차, 날씨 — 코드로 판정 | 필수 | 🟡 판정 함수 구현·테스트, 그래프 연결 2일차 |

| 번호 | 요구사항 | 이 저장소에서 |
| --- | --- | --- |
| NF3001 | API 키는 환경변수로 | `.env` (커밋 제외), `backend/config.py` 에서만 읽음 |
