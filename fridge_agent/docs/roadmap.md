# 출시까지 남은 일 (우선순위)

Google Play·App Store 출시를 기준으로 정리했다. **P0 는 출시를 막는 항목**, P1 은 핵심 기능 완성도, P2 는 차별화 기능이다.

## P0 · 출시 차단 요소

| # | 항목 | 지금 | 해야 할 일 |
| --- | --- | --- | --- |
| 1 | 계정과 데이터 보존 | 브라우저 쿠키로 가구를 구분한다. 쿠키를 잃으면 기록에 다시 접근할 수 없다 | 소셜 로그인(카카오·Google·Apple) → 계정 단위 저장, 기기 변경 시 복원, 앱 안에서 계정·데이터 삭제(Play·App Store 필수) |

| 8 | 품질 | 웹 화면 접근성 일부 | TalkBack·VoiceOver, 글자 크기 확대, 네트워크 끊김 화면, 앱 아이콘·스토어 스크린샷·설명 |

## P1 · 핵심 기능 완성도

| # | 항목 | 지금 | 해야 할 일 |
| --- | --- | --- | --- |
| 1 | 레시피 DB | 로컬 1인분 레시피 16개 → 자동 진행 후보가 두부·달걀에 몰림 | 식약처 레시피 1,000여 개를 1인분 g 구조로 변환(모델 구조화 + 사람 검수), 카테고리·조리 도구·난이도 태그 |
| 2 | 운동(Planfit 방식) | 부위별 동작 3개, 2~3개 동작 서킷 | 공개 운동 DB(free-exercise-db 등) 한글화, 시연 이미지, 세트·중량·횟수 기록, 점진적 과부하, 부위별 회복 지도, 주간 분할 |
| 3 | 재고 입력 | 이름·g·기한, 사진 후보, 바코드 | 영수증 촬영으로 여러 품목 한 번에, 자주 사는 품목 빠른 추가, 소비기한 임박 알림 |
| 4 | 영양 목표 | 사용자가 직접 목표 입력 | 키·체중·활동량으로 일반 권장 범위 안내(전문가 대체 아님 표시), 하루 부족 영양소 기반 다음 끼니 추천 |
| 5 | 코치 대화 맥락 | 이 기기에 대화 저장, 서버에는 실행 로그 | 계정별 서버 대화 저장, "아까 그거" 같은 이전 대화 참조, 응답 스트리밍 |
| 6 | 조리 모드 | SVG 장면 9종, 단계 사진, 타이머, 음성, YouTube 챕터 | 재료별 실제 손질 장면 라이브러리, 음성 명령("다음"), 화면 꺼짐 방지 |

## P2 · 차별화 · 최종 프로젝트 확장

- 인바디·건강검진 수치 입력 → 공개 기준 대비 생활 습관 안내(웰니스 범위)
- AI 조리 클립: 생성 후 사람 검수, 승인된 것만 공개(도구는 `media_tools/` 에 있음)
- 가족 공유 냉장고, 장보기 목록 공유
- 홈 화면 위젯(오늘 메뉴·물 진도), 웨어러블 연동
- Samsung Health·Health Connect 쓰기(식사·수분 기록 내보내기)

## 최종 프로젝트 산출물과의 연결

- 유스케이스: 코치 대화(자동 진행), 조리 모드, 사진 기록, 알림, 운동 세션, 계정·백업
- ERD: 계정 · 가구 · 포장(lot) · 조리/섭취 기록 · 알림 · 대화 · 실행 로그 · 계획
- 시퀀스: "상황 문장 → 해석 → 그래프(분석·계획·실행·판정·검증·응답) → 자동 진행 → 화면"
