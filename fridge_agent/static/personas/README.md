# 한끼 코치 사진

| 대화 주제 | 코치 | 파일 |
|---|---|---|
| 운동 루틴, 운동 상식, 헬스장 | 한끼 트레이너 | trainer.webp |
| 냉장고, 요리, 식단, 장보기, 레시피 영상 | 한끼 셰프 | chef.webp |
| 인사, 수면, 건강 체크, 알림, 기타 안내 | 한끼 AI | ai.webp |

제공받은 세 이미지의 비율을 유지하고 긴 변을 512px로 줄여 WebP로 저장했다. 대화 카드와 첫 인사에 같은 파일을 사용한다. 파일을 교체할 때 서버는 역할별로 WebP, PNG, JPG 순서로 선택한다.
