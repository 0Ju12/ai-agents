# 코치 캐릭터 이미지 (선택)

이 폴더에 `chef`, `trainer`, `ai` 이름의 이미지(`.webp`, `.png`, `.jpg`)를 넣으면 코치 답변의 기본 일러스트 대신 표시됩니다.

- 정사각형 256×256 이상, 얼굴·상반신이 가운데에 오도록 자른 이미지를 권장합니다.
- **사용 권리가 있는 이미지만 넣으세요.** 실존 인물(연예인 등) 사진은 본인 허락 없이 쓰면 퍼블리시티권·초상권 침해가 되고, 영화 캐릭터는 저작권·상표권 대상입니다. Google Play·App Store 심사에서도 거절 사유가 됩니다.
- 파일이 없으면 한끼 고유 일러스트(셰프·트레이너·AI)가 표시됩니다.
